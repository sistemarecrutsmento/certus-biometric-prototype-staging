# Certus biometric UX prototype — isolated homologation

This repository publishes a **synthetic-only visual prototype** for interface review.

- No real camera access, images, biometric inference, API calls, storage, or attendance writes.
- Demo always ends as unavailable / not validated and creates no attendance event.
- It is not evidence that PAD or identity matching works.
- It is a separate public static site, not the Certus production domain or the existing terminal.
- Do not put employee, participant, or sensitive data here.

The GitHub Pages URL is `https://sistemarecrutsmento.github.io/certus-biometric-prototype-staging/` once Pages reports deployment complete.
